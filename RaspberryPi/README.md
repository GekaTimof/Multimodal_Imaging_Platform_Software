# RaspberryPi

Этот код запускается на Raspberry Pi и отвечает за работу с приборами.

## Что делает

- Принимает команды от Desktop App по сети.
- Считывает данные с приборов.
- Отправляет обратно потоки данных: видео и спектры.

## Как запустить

1. Перейдите в папку Raspberry Pi:

```bash
cd RaspberryPi
```

2. Установите зависимости:

```bash
pip install -r requirements.txt
```

3. Запустите приложение:

```bash
python main.py
```

## Примечания

- Desktop App использует сеть для управления режимами Raspberry Pi.
- Этот модуль должен работать на устройстве Raspberry Pi рядом с приборами.
